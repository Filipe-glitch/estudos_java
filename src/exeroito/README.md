# Exercício 8 – Sistema de Ingressos (Java)

Este projeto é um exercício em Java que demonstra o uso de **herança** e
**sobrescrita de métodos**, simulando diferentes tipos de ingressos para eventos.

## Conceitos Trabalhados

- Programação Orientada a Objetos (POO)
- Herança (`extends`)
- Reutilização de código
- Sobrescrita de métodos
- Uso de `super`

## Objetivo

Praticar os conceitos de:
- Herança
- Construtores com `super`
- Polimorfismo
- Sobrescrita de métodos (`@Override`)
