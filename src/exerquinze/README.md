# Exercício – Sistema Bancário Simples (Java)

Este projeto é um exercício prático em Java que simula operações básicas de uma conta bancária, com foco no uso de **exceções**, **tratamento de erros** e **controle de fluxo**.

## 📌 Funcionalidades

- Criar contas bancárias
- Depositar valores
- Sacar valores
- Transferir valores entre contas
- Validar erros como: Valor inválido e Saldo insuficiente

## Conceitos Trabalhados

- Programação Orientada a Objetos (POO)
- Construtores
- Métodos com regras de negócio
- Lançamento de exceções (`throw`)
- Tratamento de exceções (`try`, `catch`, `finally`)
- Loop de repetição para validação de entrada
- Entrada de dados com `Scanner
