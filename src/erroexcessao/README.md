# Tratamento de Exceções em Java

## Descrição
Este projeto apresenta exemplos práticos de tratamento de exceções em Java,
demonstrando o uso de `try`, `catch`, `finally` e da palavra-chave `throw`.

O objetivo é compreender como o Java lida com erros em tempo de execução
(Runtime Exceptions) e como relançar exceções de forma controlada.

---

## Exemplos Implementados

### Try / Catch / Finally
- Tratamento de acesso inválido a índices de arrays
- Uso do bloco `finally`, que executa independentemente de erro

### Throw e Relançamento de Exceções
- Lançamento manual de exceções
- Captura e relançamento de exceções
- Propagação de erros entre métodos

---

## Conceitos Abordados

- RuntimeException
- NullPointerException
- ArrayIndexOutOfBoundsException
- try / catch / finally
- throw e relançamento de exceções
- Fluxo de execução em casos de erro

---

## Objetivo Educacional
Projeto desenvolvido com fins educacionais para estudo e fixação dos conceitos
de tratamento de exceções em Java.
