# Classe Data (Java)

## Descrição
Este projeto implementa uma classe `Data` em Java, responsável por representar
uma data simples composta por dia, mês e ano.  
Para fins didáticos, considera-se que todos os meses possuem 30 dias.

## Estrutura do Projeto
- `Data`: classe principal que representa a data e contém validações.
- `Principal`: classe responsável por instanciar e exibir a data.

## Regras de Validação
- Dia deve estar entre 1 e 30
- Mês deve estar entre 1 e 12
- Ano deve ser maior que zero

Caso um valor inválido seja informado, o atributo não é alterado e
uma mensagem de erro é exibida no console.

## Conceitos Aplicados
- Programação Orientada a Objetos (POO)
- Encapsulamento
- Uso de getters e setters
- Validação de dados
- Separação entre lógica e execução
