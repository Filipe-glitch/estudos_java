# Visão Geral

Este projeto demonstra conceitos fundamentais da Programação Orientada a Objetos (POO) em Java, com foco em:
- Herança
- Construtores
- Uso da palavra-chave super
- Inicialização de atributos
- Ordem de execução dos construtores

#Responsabilidade

- Representa a classe derivada (subclasse).
- Herda o atributo x da classe Base1.
- Possui o atributo próprio y.

# Conceitos Demonstrados

- Herança (extends)
- Construtores com e sem parâmetros
- Uso de super()
- Ordem de execução dos construtores
- Atributos herdados
- Encapsulamento básico
