# Exercício – Cofrinho

## Objetivo
Simular um cofrinho que armazena moedas e calcula o valor total

## Conceitos aplicados
- Programação Orientada a Objetos
- Composição
- Encapsulamento
- UML

## Classes
- Cofrinho: gerencia as moedas
- Moeda: representa uma moeda individual
