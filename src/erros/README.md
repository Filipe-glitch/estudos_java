# Tratamento de Exceções em Java

## Descrição
Este projeto reúne exemplos práticos sobre tratamento de exceções em Java,
demonstrando a diferença entre exceções **checked** e **unchecked**, o uso da
palavra-chave `throw`, e a criação de exceções personalizadas.

O objetivo é consolidar conceitos fundamentais de tratamento de erros,
essenciais para o desenvolvimento de aplicações robustas.

---

## Estrutura do Projeto

- `ExemploThrow`
  - Demonstra o uso do `throw` para lançar uma exceção manualmente.
- `ExemploUnchecked`
  - Exemplo de exceção não verificada (`IllegalArgumentException`).
- `PrincipalChecked`
  - Exemplo de exceção verificada (`IOException`) com uso de `try/catch`.
- `SaldoInsuficienteException`
  - Exemplo de exceção personalizada estendendo `RuntimeException`.

---

## Conceitos Abordados

- Exceções checked e unchecked
- Uso de `throw` e `try/catch`
- Criação de exceções personalizadas
- Tratamento de erros em operações de I/O
- Boas práticas no tratamento de exceções

---

## Tecnologias Utilizadas

- Java
- Programação Orientada a Objetos
- API de I/O (`java.io`)

---

## Objetivo Educacional

Este projeto tem finalidade educacional, sendo utilizado para estudo e
fixação dos conceitos de tratamento de exceções em Java.
