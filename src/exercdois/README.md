# Avaliação de Notas – Construtores em Java

## Descrição
Este projeto demonstra o uso de construtores em Java, incluindo
construtor padrão (vazio) e construtor com parâmetros, aplicados
a uma classe responsável por calcular médias de notas.

## Estrutura
- `Avaliacao`: classe que armazena três notas e calcula médias.
- `Principal`: classe de execução com exemplos de instanciação.

## Funcionalidades
- Criação de objetos com construtor vazio.
- Criação de objetos com construtor parametrizado.
- Cálculo de média aritmética.
- Cálculo de média ponderada.

## Conceitos abordados
- Programação Orientada a Objetos (POO)
- Construtores em Java
- Uso do operador `this`
- Métodos de instância
- Organização básica de classes

## Observações
Este código possui finalidade **educacional**, focado no
entendimento de construtores e inicialização de objetos.
