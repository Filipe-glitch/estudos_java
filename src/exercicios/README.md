# Fundamentos de Java

Este repositório contém exercícios práticos desenvolvidos durante
o estudo dos fundamentos da linguagem Java.

## Conteúdos abordados
- Métodos estáticos e membros de classe
- Diferença entre atributos estáticos e de instância
- Entrada e saída de dados com Scanner
- Estruturas de repetição
- Uso de ArrayList
- Construtores e sobrecarga

## Objetivo
Consolidar conceitos essenciais da linguagem Java
como base para estudos avançados em orientação a objetos e desenvolvimento backend.
