# Projeto Abstração com Formas Geométricas
Este projeto demonstra o uso de classes abstratas, polimorfismo e sobrescrita de métodos em Java, utilizando o exemplo de formas geométricas para cálculo de área.

# Conceitos Aplicados
- Classe abstrata (abstract)
- Método abstrato
- Polimorfismo
- Sobrescrita de métodos (@Override)
- Uso correto do Scanner
- Encapsulamento de comportamento

# Estrutura do Projeto

- FormaGeometrica
Classe abstrata que define um atributo comum (area) e um método abstrato (calculaArea).

- Circulo
Implementa o cálculo da área de um círculo.

- Quadrado
Implementa o cálculo da área de um quadrado.

- Principal
Classe responsável por executar o programa e controlar a entrada de dados.
