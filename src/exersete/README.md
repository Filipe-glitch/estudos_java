# Exercício – Sistema de Livros 

## Objetivo
Simular como se fosse uma biblioteca onde você anota informações de um livro físico e digital. Informações como autor, peso, tamanho, download etc.

## Conceitos aplicados
- Programação Orientada a Objetos
- Composição
- Encapsulamento
- UML

## Classes
- Autor: Representa as caracteristicas de um autor. 
- Livro: Representa a classe completa que será usada 
- LivroDigital: representa um livro digital
- LivroFisico: representa o livro fisico
