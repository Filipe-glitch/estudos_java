# Sistema de Avaliação de Alunos (Java)

## Descrição
Este projeto implementa um sistema simples de avaliação de alunos,
utilizando composição entre classes para representar alunos e suas
notas

## Estrutura do projeto
- `Aluno`: representa o aluno e seus dados pessoais.
- `Avaliacao`: responsável pelos cálculos de médias.
- `Principal`: classe de execução do programa.

## Conceitos abordados
- Programação Orientada a Objetos
- Composição entre classes
- Encapsulamento
- Métodos de cálculo
- Organização de código
