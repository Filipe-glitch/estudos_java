# Sistema de Matrícula e Pagamento de Alunos (Java)

## Descrição
Este projeto simula um sistema simples de matrícula de alunos em cursos,
utilizando composição entre classes para calcular o valor da mensalidade
com base em descontos aplicados ao aluno.

## Estrutura do Projeto
- `Aluno`: representa o aluno matriculado e calcula o valor a ser pago.
- `Curso`: representa o curso e sua mensalidade.
- `Principal`: classe responsável pela execução do programa.

## Funcionalidades
- Cadastro de aluno com matrícula e desconto
- Associação de um curso ao aluno
- Cálculo do valor final da mensalidade considerando o desconto

## Conceitos Aplicados
- Programação Orientada a Objetos (POO)
- Composição entre classes
- Separação de responsabilidades
- Métodos de cálculo
- Organização de código
