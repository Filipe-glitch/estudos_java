# ☕ Estudos em Java - Lógica e Programação Orientada a Objetos

Repositório dedicado aos meus estudos em **Java**, incluindo lógica de programação e conceitos de Programação Orientada a Objetos (POO).

## 🚀 Objetivo

Desenvolver uma base em Java, aplicando tanto lógica de programação quanto conceitos avançados de orientação a objetos.

## 🛠️ Tecnologias utilizadas

- Java
- Eclipse(IDE)

## 🛠️ Estrutura do projeto
- src/: código-fonte
- docs/: documentação
- docs/uml/: diagramas UML

## 📚 Conteúdos estudados

### 🔹 Lógica de Programação
- Estruturas condicionais (`if`, `switch`)
- Estruturas de repetição (`for`, `while`)
- Funções e métodos
- Manipulação de strings
- Arrays, listas e dicionários
- Tratamento de exceções (`try/catch`)
- UML

### 🔹 Programação Orientada a Objetos (POO)
- Encapsulamento
- Herança
- Polimorfismo
- Classes abstratas

## 📌 Aprendizados

- Estrutura de aplicações em Java
- Aplicação prática de POO
- Organização e reutilização de código
